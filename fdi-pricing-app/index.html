    Pricing rules

    • Eligible pillars: CX, ERP, HCM, and SCM. Fusion Operational Analytics requires the matching FDI Base pillar. You may purchase it for any subset of your FDI Base pillars.
    • FDI Base minimum per pillar: 10 Hosted Named Users or 1,000 Hosted Employees. Minimums and quantity limits apply separately to each pillar, not to combined totals.
    • FDI Base Hosted Named User requires Fusion Operational Analytics Hosted Named User. FDI Base Hosted Employee allows either Hosted Named User or Hosted Employee for Fusion Operational Analytics.
    • Fusion Operational Analytics Hosted Named User: minimum 35 per pillar; cannot exceed the matching FDI Base quantity under either metric. FDI Base quantities below 35 cannot support this option.
    • Fusion Operational Analytics Hosted Employee: minimum 1,200 per pillar; quantity must equal the matching FDI Base Hosted Employee quantity. Both conditions apply, so that FDI Base quantity must also be at least 1,200.
